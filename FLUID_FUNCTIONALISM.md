# Fluid Functionalism

Компоненты и motion-паттерны добавляются через официальный shadcn registry.

```bash
npx shadcn@latest registry add @fluid
npx shadcn@latest add @fluid/button
npx shadcn@latest add @fluid/tabs
npx shadcn@latest add @fluid/card
```

Для текущей HTML-страницы визуальные состояния уже адаптированы в `styles.css` и `script.js`. При переходе на React-компоненты используются те же токены и поведение Fluid Functionalism.
